Для запуска программм рекомендуется иметь интерпритатор Python версии 3.10
Его можно скачать с данного сайта:
https://www.python.org/downloads/release/python-3100/

Затем в данном проекте необходимо создать виртуальное окружение.
Нужно в командной строке bash ввести следующую команду:
python -m venv venv

Для запуска виртуального окружения в Windows необходимо в командной строке bash воспользоваться командой:
source venv/Scripts/activate

# Задача 1(Алгоритмы):

Запустить программу можно в командной строке bash с помощью команды:
python task1.py

# Задача 2(Автоматизация тестирования c Selenium)

Перед запуском необходимо установить соответствующие библиотеки.
В командной строке bash нужно воспользоваться командой:
pip install requirements.txt
В файле requirements.txt находится список необходимых библиотек

Затем запустить программу можно в командной строке bash с помощью команды:
python task2.py
